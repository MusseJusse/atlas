Three ways to rethink Atlas

Right now Atlas is three layers stacked around a chart: a sidebar of 13 checkboxes and 6 reasoning chips, a strip of 7 metric tabs, and a settings button. Each tab shows one metric, so checking a model's score, cost, and speed together means clicking through three views and remembering the numbers. Each direction below removes one of those layers instead of polishing it. All three keep cobalt and DM Sans and use the {{SNAPSHOT}} snapshot, so every point and number is real.

  • A. Canvas
  • B. Matrix
  • C. Budget
  • Comparison

A. Canvas

The chart becomes the whole page. The axis titles turn into menus, so the 7 tabs collapse into two questions: what goes up, and what goes across. Choosing "Nothing" for the x axis gives a ranked bar chart, which covers today's Intelligence and Omniscience views. The labels at the end of each line toggle models, and the search field adds new ones, so the sidebar goes away.

{{MOCK_A}}
  • The Frontier switch fades every configuration that some cheaper one beats, instead of just drawing a line over them.
  • Clicking a point pins its card next to the point, with a leader line. Phones use a bottom sheet.
  • The reasoning filter moves into the top bar as a multi-select.
  • Build size: medium. The scatter and bar code stay. State changes from one view to an {x, y} pair, and old URLs need a mapping.

B. Matrix

This one shows every metric at once. Each row is a model, and each cell plots all five reasoning levels on that column's scale, with the number for the level you picked. You can see that GPT-6.2 Sol at high lands 7 points under Fable 5.2 for a sixteenth of the cost, finishes 3 times faster, and burns a fifth of the tokens. That comparison takes four tab switches today.

{{MOCK_B}}
  • The reasoning picker sits inside the headline, so the sentence says what you're looking at.
  • Headers sort. Each column shares one scale, so you compare dot positions down a column.
  • On phones, one metric shows at a time with full-width strips. The tabs live on as a column picker.
  • Build size: medium. It's new code, but small SVG strips are simpler than the scatter.
{{MOCK_B_PHONE}}

C. Budget

Start from the question people actually bring: what's the smartest thing I can run for this much per task? Set a price and the page answers with each model's best configuration under it, plus how far that is from the top score at any price. The slider works in this mock. Try $0.10 and $5.

{{MOCK_C}}
  • The answer is a sentence set in the display cut, and it rewrites as you drag.
  • Models that can't fit the budget stay listed with their cheapest price, so they don't silently disappear.
  • The chart shades everything over budget instead of hiding it.
  • Build size: small. It reuses the scatter, adds one derived list, and fits the URL state as ?budget=1.
